## خطوات التسطيب

1. حمّل الملف من اللينك اللي فوق
2. أول مرة بس، أندرويد هيسأل: **«السماح بالتثبيت من هذا المصدر؟»** — اضغط **سماح**
   (ده طبيعي لأن التطبيق بيتوزّع مباشرة مش من جوجل بلاي)
3. اضغط **تثبيت**
4. افتح التطبيق وادخل برقم موبايلك والباسورد اللي الإدارة عملتهم لك
